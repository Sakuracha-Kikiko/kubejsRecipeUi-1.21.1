# kubejsRecipeUi

`kubejsRecipeUi` 是一个基于 Minecraft 1.26.1、NeoForge 和 KubeJS 的可视化配方编辑附属模组，作者为 mubai。

它将常用的 KubeJS 配方修改流程放进游戏内界面中：玩家可以像使用原版工作台、熔炉、烟熏炉、高炉、切石机和锻造台一样编辑配方，设置材料、标签、替代材料、NBT/数据组件以及输出数量，并生成可直接用于 KubeJS 的脚本代码。

## 主要功能

- 提供工作台编辑器方块，并加入独立的创造物品栏。
- 使用接近原版工作站的界面布局，移除不需要的配方书区域。
- 支持有序配方和无序配方切换。
- 支持工作台、熔炉、烟熏炉、高炉、切石机和锻造台等配方类型。
- 支持精确物品、物品标签和替代材料。
- 可从槽位读取物品的数据组件/NBT，并选择是否参与配方匹配。
- 支持通过 JEI 将配方材料和配方 ID 自动填入编辑器。
- 支持仅新增、删除后新增和仅删除等配方修改方式。
- 支持按配方 ID、类型、来源模组、分组、输入材料或输出物品删除配方。
- 提供代码预览，只有预览后的代码才会写入 `generated_recipes.js`。
- 提供 KubeJS 事件编辑界面，可选择事件、脚本端和事件方法，并生成参数注释。

## 依赖

- Minecraft `26.1.2`
- NeoForge `26.1.2` 系列
- KubeJS `8.0.3` 或更高版本
- LDLib2 `26.1.2` 系列（必需）
- JEI `29.x`（可选，用于配方查看和自动填充）

## 使用方式

1. 安装 NeoForge、KubeJS 和必需的 LDLib2。
2. 将模组放入对应实例的 `mods` 文件夹。
3. 进入游戏后，从创造物品栏的“KubeJS 配方工具”标签中取得“工作台编辑器”。
4. 放置并打开编辑器，设置配方后点击“预览”，确认代码无误后再点击“写入”。

## 开发环境

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

项目使用 Java 25。JEI 仅作为可选运行时集成，开发环境会默认加载。
