# LDLib2 编辑器界面设计

## 目标

将配方界面改造成 LDLib2 驱动的 JEI 浅色编辑器风格，同时保留工作台、熔炉、烟熏炉、高炉、营火、切石机、锻造台、可选模组配方、JEI 填充和配方脚本写入能力。

## 视觉方向

- 使用 `StylesheetManager.MC` 作为主样式表，复用原版浅灰面板、槽框、按钮、输入框和斜边框纹理。
- 根窗口采用紧凑的 `600×360` 编辑器比例，顶部为居中标题工具栏，左侧为 34 像素图标导航。
- 侧栏入口使用无文字的 `20×20` 按钮和独立 `16×16` 物品图标，避免前置图标受空文字节点与全局按钮内边距影响。
- 标题栏使用中灰底色与白字，正文使用浅灰背景与深色文字，形成与 JEI 配方页一致的层级。
- 输入框、下拉框、候选浮层和代码编辑区统一覆盖为浅色背景与深色文字，保证整个编辑器视觉一致。
- 主工作区使用 `SplitView.Horizontal` 按 `64/36` 分隔配方画布与属性检查器。
- 右侧蓝框使用 `TabView` 在配方属性、代码预览和 JEI 来源三种模式间切换，每种模式都占满右栏。
- 属性检查器使用 `ScrollerView`，避免不同 GUI 缩放下控件重叠。
- 底部使用 `TabView` 展示代码预览与 JEI 配方来源信息。
- 数据组件参与开关使用 LDLib2 `Switch`，替代文字 Toggle。
- 工作站配方区和 AE2 JEI 分类使用独立浅色边框，避免槽位、标签和箭头融入背景。
- 中央配方容器与内部 JEI 画布均使用浅灰填充，不允许原版 `BORDER` 的深色内部区域残留。

## 配方编辑布局

顶部标题栏显示当前工作站类型并保持居中。左侧导航按钮使用工作站物品图标。中央配方画布使用固定 190 像素配方框和独立 97 像素背包框；背包槽位明确使用 `162×77` 尺寸，保证快捷栏不越过背景边框，9×9 Extended Crafting 网格也不会挤压背包。右侧蓝框在属性、代码和来源模式间切换，属性模式集中展示写入模式、配方形状、删除条件、配方 ID、输入/输出数据组件开关以及预览和写入操作。

小型工作站面板的固定宽度内容必须由父级列布局在配方框内水平居中。熔炉、烟熏炉和高炉共享 `176×76` 原版槽位画布，AE2 充能器使用 `130×50` JEI 画布，这些画布都不能依赖自动外边距或贴靠配方框左侧。

右侧默认显示配方属性；点击预览成功生成代码后自动切换到 JavaScript 代码模式，JEI 来源模式显示配方 ID、类型、来源模组和分组。写入前仍只读取代码编辑器当前内容，空内容在游戏聊天栏与界面中提示。

## 验收标准

- 游戏运行时使用 LDLib2 `MC` 浅色样式。
- 配方编辑器不再使用单列堆叠布局。
- `SplitView.Horizontal`、`TabView`、`ScrollerView` 和 `Switch` 均在实际界面中使用。
- JEI 填充、槽位编辑、配方生成和脚本写入逻辑保持可用。
- `gradlew build` 成功，语言 JSON 为有效 UTF-8 JSON。
