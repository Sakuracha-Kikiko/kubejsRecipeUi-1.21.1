# LDLib2 编辑器界面设计

## 目标

将现有单列式配方界面改造成 LDLib2 原生编辑器风格，同时保留工作台、熔炉、烟熏炉、高炉、营火、切石机、锻造台、JEI 填充和配方脚本写入能力。

## 视觉方向

- 使用 `StylesheetManager.MODERN` 作为主样式表。
- 根窗口采用宽屏编辑器比例，顶部为标题工具栏，左侧为图标导航。
- 主工作区使用 `SplitView.Horizontal` 分隔配方画布与属性检查器。
- 使用 `SplitView.Vertical` 提供可拖动的底部代码区域。
- 属性检查器使用 `ScrollerView`，避免不同 GUI 缩放下控件重叠。
- 底部使用 `TabView` 展示代码预览与 JEI 配方来源信息。
- NBT 参与开关使用 LDLib2 `Switch`，替代原有文字 Toggle。

## 配方编辑布局

顶部标题栏显示当前工作站类型。左侧导航按钮使用工作站物品图标。中央配方画布保留原版工作站的槽位关系和玩家背包，右侧检查器集中展示写入模式、配方形状、删除条件、配方 ID、输入/输出数据组件开关以及预览和写入操作。

底部代码区默认显示 JavaScript 预览；第二个标签页显示从 JEI 读取的配方 ID、类型、来源模组和分组。写入前仍只读取代码编辑器当前内容，空内容在游戏聊天栏与界面中提示。

## 验收标准

- 游戏运行时使用 LDLib2 `MODERN` 样式。
- 配方编辑器不再使用单列堆叠布局。
- `SplitView`、`TabView`、`ScrollerView` 和 `Switch` 均在实际界面中使用。
- JEI 填充、槽位编辑、配方生成和脚本写入逻辑保持可用。
- `gradlew build` 成功，语言 JSON 为有效 UTF-8 JSON。
