# 多工作方块配方编辑器设计

## 范围

工作台编辑器增加左侧工作方块切换栏，支持工作台、熔炉、烟熏炉、高炉、切石机和锻造台。切换按钮使用对应原版方块图标、悬浮提示和明确选中态。右侧继续使用 LDLib2，按所选类型展示接近原版的槽位关系，并保留玩家背包、JEI 幻影拖入、原料标签、数据组件、生成预览和脚本写入能力。

## 配方模型

每种工作方块拥有独立编辑状态，切换类型不会丢失已放入的原料和输出。工作台使用九个原料槽及有序/无序状态；三种炉子和切石机使用一个原料槽；锻造台依次使用模板、基础和追加材料三个槽。炉子配方额外保存经验值和烹饪时间。

统一配方定义携带工作方块类型、原料列表、输出、工作台模式以及炉子参数。验证规则由类型决定，防止用错误的槽位数量生成脚本。

## 代码生成

生成器按类型输出 KubeJS 8.0.3 的快捷方法：

- `event.shaped` / `event.shapeless`
- `event.smelting`
- `event.smoking`
- `event.blasting`
- `event.stonecutting`
- `event.smithing`

炉子配方在基础调用后追加 `.xp(...)` 和 `.cookingTime(...)`。所有类型继续生成一个 `ServerEvents.recipes` 外壳，现有脚本存储逻辑负责首次创建和后续插入。

## 界面与错误处理

左侧栏固定宽度，六个图标按钮不改变主编辑区域尺寸。当前类型按钮禁用以表现选中态。工作台之外隐藏有序/无序按钮。数值字段限制经验值非负、时间至少一 tick。输入为空、输出为空、锻造材料不完整或数值无效时，在原界面显示错误通知且不关闭编辑器。

## 验证

不增加单元测试。执行 `gradlew build -x test`，随后保证只有一个客户端实例并运行 `gradlew runClient`。逐个切换六个按钮，验证布局、状态保留、JEI/玩家背包放入、代码预览和写入结果。
