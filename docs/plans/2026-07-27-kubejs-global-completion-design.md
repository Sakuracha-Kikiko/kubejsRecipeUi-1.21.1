# KubeJS 全局代码提示设计

## 目标

在事件编辑器的 LDLib2 `CodeEditor` 中提供不依赖 ProbeJS 的 KubeJS 全局代码提示。提示范围覆盖 JavaScript 关键字、KubeJS 全局绑定、所有已注册事件、当前事件对象方法、常用代码片段以及注册表资源 ID，并允许第三方 KubeJS 插件通过标准事件注册自动进入提示索引。

## 数据来源

补全索引完全在游戏内构建，不增加外部模组依赖：

- 使用 `KubeJsEventCatalog` 读取 KubeJS 和第三方插件注册的事件组、事件名、脚本端、目标类型及事件类。
- 使用 KubeJS 插件注册过程和核心绑定目录收集 `ServerEvents`、`Item`、`Ingredient`、`Text`、`Platform` 等全局符号。
- 对全局绑定类型和当前事件类型执行受控 Java 反射，过滤 `Object`、桥接方法、合成方法和 `@HideFromJS` 成员，生成方法签名、参数及返回类型。
- 使用 Minecraft 注册表收集物品、方块、流体、实体类型、标签和配方类型资源 ID。
- 内置少量 JavaScript 关键字和高价值 KubeJS 代码片段，补足无法从反射推导的语法结构。

## 补全上下文

补全引擎只分析光标所在行和必要的前缀，不执行用户代码：

- 普通标识符位置提示全局绑定、事件组、关键字和代码片段。
- `ServerEvents.`、`BlockEvents.` 等事件组后提示该组全部事件，并插入监听器骨架。
- `event.` 后只提示当前所选事件能够使用的方法。
- `Item.`、`Text.`、`Ingredient.` 等全局对象后提示对应静态或实例方法。
- `Item.of('...')`、`Block.id('...')`、`Fluid.of('...')` 等字符串参数中提示对应注册表 ID 和标签。

每次最多显示有限数量的高相关候选，先按前缀匹配，再按包含匹配和名称排序，避免上千个注册表条目卡顿。

## 编辑器交互

新增 `KubeJsCodeEditor` 扩展 LDLib2 `CodeEditor`，保留原有语法高亮、中文字体和编辑功能。输入字符、移动光标或按 `Ctrl+Space` 时刷新候选；输入 `.` 和资源 ID 引号时自动打开提示。

提示浮层位于代码区域右上方，显示图标类别、候选名称、签名和中文说明。支持：

- `↑` / `↓` 切换候选。
- `Enter` 或 `Tab` 插入。
- `Esc` 关闭。
- 鼠标点击插入。
- 插入方法后将光标放到括号内。

浮层只在存在候选时显示，不抢占普通换行、Tab 和方向键操作。

## 容错与性能

- 单个第三方插件或反射类型读取失败时仅跳过对应来源，并记录一次调试日志。
- 全局索引按脚本端缓存，事件方法按事件类缓存，注册表 ID 在界面创建时生成快照。
- 不调用或执行补全对象的方法，不解析完整 JavaScript AST，也不访问网络。
- 客户端测试重点检查全局提示、事件组提示、`event.` 方法提示、资源 ID 提示、键盘插入以及中文显示。
