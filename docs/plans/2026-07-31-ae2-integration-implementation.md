# Applied Energistics 2 配方编辑实现计划

## 第一步：可选依赖与工作站模型

- 为 AE2 增加 `compileOnly`、开发运行依赖和可选模组元数据。
- 重构工作站可用性判断，加入四种 AE2 工作站并共用一个侧栏入口。
- 验证：未安装 AE2 时工作站列表不包含 AE2 类型。

## 第二步：配方状态与代码生成

- 新增 `Ae2RecipeSettings`，扩展 `RecipeDefinition` 和 `RecipeEditorSession`。
- 为充能器、压印器、物品转化和熵变处理生成带 ID 的 `event.custom` 代码。
- 验证：`compileJava` 通过，四类 JSON 字段与 AE2 26.1 数据格式一致。

## 第三步：LDLib2 编辑界面

- 增加 AE2 类型下拉框及四个配方面板。
- 四个面板按 AE2 自带 JEI 分类的原始尺寸、坐标和纹理绘制，编辑参数位于 JEI 画布下方。
- 保留物品槽的标签、替代材料、数据组件和输出数量能力。
- 为熵变处理提供模式、资源类型和资源 ID 控件。
- 验证：切换四类编辑器时独立状态得到保留。

## 第四步：JEI 自动填充

- 为四个 AE2 JEI 配方类型注册转移处理器。
- 回填材料、输出、配方 ID、来源信息和 AE2 专属参数。
- 验证：流体熵变和流体转化条件不会因缺少物品槽而丢失。

## 第五步：构建检查

- 执行 `compileJava` 和完整 `build`。
- 比较中英文翻译键，检查 UTF-8 与 Git 空白错误。
- 检查发布 JAR 未捆绑 AE2 或 GuideME 类。
